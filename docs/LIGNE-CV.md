# Ligne de CV

Une ligne vraie et vérifiable, sans année, sans client, sans superlatif. Les deux chiffres qui la
portent sont dans le dépôt : `.mcp-migrate-delta/delta.json` produit par `npm run test:network`
(36 scénarios scorés en échec avant, 0 après) et `docs/ecosystem/2026-09-06.json` (0 serveur sur 30
déclarant la révision courante).

Auteur de `mcp-migrate-delta` (npm, Apache-2.0) : mesure d'une migration MCP `2025-11-25` vers
`2026-07-28` en rejouant la suite de conformance officielle avant et après, 36 scénarios en échec
vers 0 sur les serveurs de référence livrés, et mesure d'écosystème sur 30 serveurs publics du
registre, dont 0 déclare la révision courante. https://www.npmjs.com/package/mcp-migrate-delta
